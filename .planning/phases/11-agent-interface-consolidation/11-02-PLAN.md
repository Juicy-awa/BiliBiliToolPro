Replace with ONE registration:

WHY MutatingPolicy: IChargeApi and IVideoApi (mutating methods: Charge, AddCoinForVideo, etc.)
were already using MutatingPolicy. Since the merged interface contains these methods, the
conservative MutatingPolicy must apply to the whole interface (prevents retry on mutating calls).

```csharp

```
