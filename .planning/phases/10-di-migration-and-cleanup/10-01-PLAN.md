**IQingLongApi.cs** — write the complete file:
```csharp
using Ray.BiliBiliTool.Agent.QingLong.Dtos;
using Refit;

namespace Ray.BiliBiliTool.Agent.QingLong;

public interface IQingLongApi
{
    [Get("/open/auth/token")]
    Task<QingLongGenericResponse<TokenResponse>> GetTokenAsync(
        [Query] string client_id,
        [Query] string client_secret
    );

    [Get("/open/envs")]
    Task<QingLongGenericResponse<List<QingLongEnv>>> GetEnvsAsync(
        [Query] string searchValue,
        [Header("Authorization")] string token
    );

    [Post("/open/envs")]
    Task<QingLongGenericResponse<List<QingLongEnv>>> AddEnvsAsync(
        [Body] List<AddQingLongEnv> envs,
        [Header("Authorization")] string token
    );

    [Put("/open/envs")]
    Task<QingLongGenericResponse<QingLongEnv>> UpdateEnvsAsync(
        [Body] UpdateQingLongEnv env,
        [Header("Authorization")] string token
    );
}
```

Rules for IQingLongApi:
- `client_id`, `client_secret`, `searchValue` are GET query params NOT in the URL template — they MUST get `[Query]`
- `[Header("Authorization")]` param attribute is unchanged (Refit supports it identically)
- `[Body]` uses default JSON serialization (correct for POST/PUT with object bodies)
- No class-level `[Headers]` needed — the QingLong base URL is set via `c.BaseAddress`
