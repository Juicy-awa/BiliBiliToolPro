| test host boot -> real startup seams | Host integration fixtures exercise production startup code and must not mutate production behavior to make tests pass |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02-02 | D | host integration fixtures | mitigate | Keep fixtures minimal and boot the real host seams from Phase 1 instead of inventing alternate startup paths. |
| T-02-03 | R | diagnostics capture utility | mitigate | Centralize in-memory log capture in the characterization project so later tests assert stable markers rather than ad hoc file reads. |
</threat_model>
