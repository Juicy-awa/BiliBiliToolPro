| Boundary | Description |
|----------|-------------|
| host startup code -> application service resolution | Thin-host assumptions can silently regress if startup code absorbs orchestration again |
| scheduler registration -> job execution path | Scheduled flows can drift away from application-entry delegation if tests do not lock the seam |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-07 | T | Web and Console startup paths | mitigate | Boot the real startup paths under test and assert critical service resolution and scheduler registration. |
| T-02-08 | E | Console hosted service and Quartz jobs | mitigate | Add delegation safety tests that fail if host entry points stop routing through application services. |
| T-02-09 | D | host integration suite | accept | Host tests intentionally stop at startup seams and service resolution, not real remote IO, to keep them deterministic and fast enough for ongoing use. |
</threat_model>
