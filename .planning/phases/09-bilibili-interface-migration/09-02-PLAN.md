## Universal attribute mapping (WebApiClientCore → Refit)

| WebApiClientCore | Refit | Notes |
|---|---|---|
| `using WebApiClientCore.Attributes;` | `using Refit;` | always replace |
| `using Ray.BiliBiliTool.Agent.Attributes;` | _(remove)_ | no AppendHeader in Refit |
| `: IBiliBiliApi` | _(remove from inheritance)_ | file deleted in Plan 01 |
| `[HttpGet("/path")]` | `[Get("/path")]` | |
| `[HttpPost("/path")]` | `[Post("/path")]` | |
| `[HttpPut("/path")]` | `[Put("/path")]` | |
| `[FormContent]` param | `[Body(BodySerializationMethod.UrlEncoded)]` param | |
| `[JsonContent]` param | `[Body]` param | |
| `[PathQuery]` param | `[Query]` param | |
| Complex object on GET, no attribute, not in URL `{}` template | add `[Query]` | |
| `[Header("Name", "Value")]` on method/interface | `[Headers("Name: Value")]` | plural, colon format |
| `[AppendHeader("Name", "Value", ...)]` on method/interface | `[Headers("Name: Value")]` | plural, colon format |
| `[Header("Name")]` on parameter | `[Header("Name")]` param | unchanged |
| `[AppendHeader("Name")]` on parameter | `[Header("Name")]` param | rename only |
| `[JsonReturn(...)]` | _(delete entirely)_ | Refit default |
| `[LogFilter]` or `[LogFilter(false)]` | _(delete entirely)_ | LogDelegatingHandler is global |
| `[RawFormContent]` on string param | `[Body]` param + add `[Headers("Content-Type: application/x-www-form-urlencoded")]` to method | see ILiveApi.LikeLiveRoom |

## Special case: IVipBigPointApi.StartOgvWatchAsync and CompleteOgvWatchAsync
These two methods have no HTTP verb attribute in the current file (they are stubs). Keep them without a verb attribute — Refit will throw NotImplementedException if called, which is more explicit than WebApiClientCore's undefined behavior.

## Note on IVipMallApi and IVipBigPointApi and IMallApi
These interfaces do NOT inherit IBiliBiliApi (never did). They have [LogFilter] directly on the interface — just delete [LogFilter]. No `: IBiliBiliApi` to remove.

IUserInfoApi, IUpInfoApi, IDailyTaskApi, IRelationApi, IChargeApi, IVideoApi, IArticleApi, IAccountApi, IBiliBiliApi
