## Universal attribute mapping (WebApiClientCore → Refit)

| WebApiClientCore | Refit | Notes |
|---|---|---|
| `using WebApiClientCore.Attributes;` | `using Refit;` | always replace |
| `using Ray.BiliBiliTool.Agent.Attributes;` | _(remove)_ | AppendHeader no longer needed |
| `: IBiliBiliApi` | _(remove from inheritance)_ | IBiliBiliApi is being deleted |
| `[HttpGet("/path")]` | `[Get("/path")]` | |
| `[HttpPost("/path")]` | `[Post("/path")]` | |
| `[HttpPut("/path")]` | `[Put("/path")]` | |
| `[FormContent]` param | `[Body(BodySerializationMethod.UrlEncoded)]` param | |
| `[JsonContent]` param | `[Body]` param | |
| `[PathQuery]` param | `[Query]` param | |
| Complex object on GET, no attribute, not in URL `{}` template | add `[Query]` | e.g., GetFollowingsRequest request |
| `[Header("Name", "Value")]` on method/interface | `[Headers("Name: Value")]` | note plural, colon format |
| `[AppendHeader("Name", "Value", ...)]` on method/interface | `[Headers("Name: Value")]` | note plural, colon format |
| `[Header("Name")]` on parameter | `[Header("Name")]` param | unchanged (Refit uses same) |
| `[AppendHeader("Name")]` on parameter | `[Header("Name")]` param | rename only |
| `[JsonReturn(...)]` on method | _(delete entirely)_ | Refit returns JSON by default |
| `[LogFilter]` or `[LogFilter(false)]` | _(delete entirely)_ | LogDelegatingHandler is global |
