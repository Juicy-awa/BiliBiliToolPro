## Critical Bug Found and Fixed During Audit

**Bug:** Commit `8370b38` (merge IMallApi) accidentally deleted 7 DI registrations.  
**Impact:** Application would fail at runtime for: Coin, Donate, Article, Charge, Live, Manga, VipBigPoint, Login tasks.  
**Detection:** Audit-phase codebase inspection (integration tests did not catch it — they test startup, not DI resolution of all services).  
**Fix:** Commit `8d56f41` restored all 7 registrations with correct hosts and policies.
