## v4.0.0.3 Requirements (Archived)

Migrate the Agent layer HTTP client abstraction from WebApiClientCore to Refit — 18 interfaces, DI registration, and associated infrastructure. Pure internal library swap; all API behavior and existing tests were preserved.

### Agent Layer

- [x] **REFIT-01**: Maintainer can see all 17 Bilibili HTTP client interfaces using Refit attributes (`[Get]`, `[Post]`, `[Body]`, `[Query]`, `[Headers]`) instead of WebApiClientCore attributes
- [x] **REFIT-02**: Maintainer can see `IQingLongApi` using Refit attributes instead of WebApiClientCore attributes
- [x] **REFIT-03**: Maintainer can see DI registration using `AddRefitClient<T>` with the same delegating handlers and Polly policies as before
- [x] **REFIT-04**: Maintainer can see `IBiliBiliApi` common headers injected by `BiliBiliCommonHeadersDelegatingHandler` instead of `AppendHeaderAttribute`
- [x] **REFIT-05**: Maintainer can verify WebApiClientCore package is removed; `AppendHeaderAttribute.cs`, `AppendHeaderType.cs`, and `LogFilterAttribute.cs` are deleted; Refit packages added
- [x] **REFIT-06**: Maintainer can verify the build passes with 0 errors and existing architecture tests (4/4) and integration tests (7/7) pass
