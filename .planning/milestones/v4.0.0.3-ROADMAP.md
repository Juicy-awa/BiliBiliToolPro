## Milestone Summary

Replaced WebApiClientCore with Refit 8.0.0 as the HTTP client abstraction across all 18 Agent-layer interfaces. Pure library swap — all API behavior, Polly policies, delegating handler chains, and test results preserved identically.

### Key Accomplishments

1. **Refit 8.0.0 infrastructure** — Added Refit packages, created `BiliBiliCommonHeadersDelegatingHandler` to inject 6 Bilibili common headers (replacing `AppendHeaderAttribute`), wired it outermost in the delegating handler chain
2. **17 Bilibili interfaces migrated** — All `[HttpGet]`/`[HttpPost]`/`[FormContent]`/`[JsonContent]`/`[PathQuery]` attributes replaced with Refit equivalents; `IBiliBiliApi` empty marker interface deleted
3. **IQingLongApi migrated** — GET/POST/PUT endpoints converted with `[Query]`, `[Body]`, `[Header]` Refit attributes
4. **DI fully migrated** — All `AddHttpApi<T>` replaced with `AddRefitClient<T>().ConfigureHttpClient(...)` preserving Polly policies and handler chains
5. **WebApiClientCore removed** — Package removed from `Directory.Packages.props` and `Agent.csproj`; 4 legacy attribute files deleted
6. **IVideoApi URL template bug fixed** — `{aid}` and `{playedTime}` template params added as explicit method params (WebApiClientCore resolved from DTO body implicitly; Refit requires explicit)

### Decisions Made

| Decision | Outcome |
|----------|---------|
| Refit 8.0.0 not 10.1.6 | 10.1.6 requires `Microsoft.Extensions.Http >= 9.0.3`, incompatible with .NET 8 pin at 8.0.1 |
| Handler chain order: Log → CommonHeaders → Interval → Polly → Wrid | Logging outermost for complete request visibility |
| IVipBigPointApi stub methods kept without HTTP verb | No HTTP verb known; RF001 warning is acceptable (pre-existing) |
| ILiveApi `RawFormContent` → `[Body] string` + method-level `[Headers]` | Closest Refit equivalent for raw form content |

### Known Issues / Tech Debt

- RF001 warnings on `IVipBigPointApi.StartOgvWatchAsync` and `CompleteOgvWatchAsync` — pre-existing, no HTTP verb known
- One comment in `BiliBiliCommonHeadersDelegatingHandler.cs` L5 references WebApiClientCore for historical context — intentional
